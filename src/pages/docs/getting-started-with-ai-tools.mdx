## 🏗️ Step 2: Create Your First Project (10 minutes)

Time to build something! We'll create a website that can talk to Cardano wallets.

### The Magic Command (Works Every Time)

1. **Open your AI tool** (we'll use Cursor in this example)
2. **Open the terminal:** Press `Cmd+Shift+P` (Mac) or `Ctrl+Shift+P` (Windows), then type "Terminal"
3. **Copy this magic spell:**
   ```bash
   npx create-next-app@latest my-first-cardano-app --typescript --tailwind --app
   ```
4. **Paste it and press Enter**
5. **Wait 2-3 minutes** while it downloads everything (perfect time for coffee! ☕)

**What just happened?** You created a professional website framework. It's like getting a house with all the plumbing and electricity already installed.

### Start Your App

1. **Navigate to your project:**
   ```bash
   cd my-first-cardano-app
   ```
2. **Start the development server:**
   ```bash
   npm run dev
   ```
3. **Open your browser** and go to: `http://localhost:3000`

🎉 **Congratulations!** You just built a website! It's running on your computer right now.

## 🔗 Step 3: Add Cardano Superpowers (10 minutes)

Now let's give your app the ability to connect to Cardano wallets. This is where the magic happens!

### Install the Cardano Toolkit

**In your terminal, type:**

```bash
npm install @meshsdk/core @meshsdk/react
```

**Wait 30 seconds** and you're done! Your app now has Cardano superpowers. 🦸‍♂️

### Add a Wallet Connector (Copy-Paste Magic)

1. **Find the file** `src/app/page.tsx` in your project
2. **Delete everything** in that file (don't worry, we're replacing it with something better)
3. **Copy and paste this code:**

```jsx
"use client";
import { CardanoWallet } from "@meshsdk/react";

export default function Home() {
  return (
    <div className="min-h-screen bg-gray-900 text-white">
      <div className="container mx-auto px-4 py-16 text-center">
        <h1 className="text-6xl font-bold mb-8 bg-gradient-to-r from-sky-400 to-emerald-400 bg-clip-text text-transparent">
          My First Cardano App! 🚀
        </h1>

        <p className="text-2xl text-gray-300 mb-12 max-w-2xl mx-auto">
          I built this with AI in 30 minutes. No programming experience needed!
        </p>

        <div className="bg-gray-800 border border-gray-700 rounded-2xl p-8 max-w-md mx-auto">
          <h2 className="text-2xl font-bold mb-6 text-emerald-400">
            Connect Your Wallet
          </h2>
          <CardanoWallet isDark={true} />
          <p className="text-sm text-gray-400 mt-4">
            ✨ This actually works! Try connecting your Eternl or Nami wallet.
          </p>
        </div>

        <div className="mt-12 text-gray-400">
          <p>🎉 You just built a blockchain app!</p>
          <p>Time to build something bigger...</p>
        </div>
      </div>
    </div>
  );
}
```

4. **Save the file** (`Cmd+S` or `Ctrl+S`)
5. **Check your browser** - it should automatically refresh

🔮 **Magic Moment:** You now have a working Cardano wallet connector! If you have a Cardano wallet installed, you can actually connect it.

## 🆘 Need Help?

**Stuck on something?** That's totally normal! Here's what to do:

### 🔧 Common Issues & Quick Fixes

**"My terminal says command not found"**

- Make sure you have Node.js installed: [nodejs.org](https://nodejs.org)
- Restart your terminal and try again

**"The wallet won't connect"**

- Make sure you have a Cardano wallet installed (Eternl, Nami, or Flint)
- Try refreshing the page

**"The code doesn't work"**

- Copy the error message
- Paste it into ChatGPT with: "How do I fix this error in my Cardano app?"
- Follow the AI's suggestions
